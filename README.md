# Мониторинг цен для Windows

Новая реализация с чистого листа: приложение для Windows-виртуалки на домашнем Proxmox.

Согласованные требования:

- Мониторинг выбранных товаров Wildberries и Ozon.
- Для Ozon отслеживается цена по карте.
- Уведомления об изменениях по заданным условиям приходят в Telegram-группу.
- Товары, настройки, история и браузерный профиль хранятся локально.
- При необходимости владелец проходит CAPTCHA вручную в окне браузера.

Предыдущий код серверного бота, локальная база и окружение удалены. История Git сохранена. Код новой Windows-версии пока не реализован.
