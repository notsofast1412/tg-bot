# Диагностика Ozon на домашней VM

Основной компьютер владельца работает под Windows; бот установлен на Ubuntu
22.04 в виртуалке. Одинаковый внешний IPv4 не исключает различий IPv6,
версии браузера, DNS или сохранённой сессии. HTTP-клиент, Playwright и старый
Chromium на VM получили отказ. CAPTCHA вручную пока не дала доступ к карточке.

## Проверка версии и времени

В терминале Ubuntu: `date -u`, `timedatectl show -p NTPSynchronized` и
`/opt/paintbot/var/chromium/chromium-1187/chrome-linux/chrome --version`.
На Windows посмотрите версию в меню «О браузере». В старом launcher был
жёстко задан Chromium из Playwright 1.55.0. Исправленный launcher предпочитает
системный стабильный браузер, позволяет указать `--browser` и открывает
карточку 197922669 по умолчанию. Sandbox остаётся включённым, прокси не используются.

## Актуальный браузер

Остановите только VNC-браузер, запущенный для проверки, через Ctrl+C в его
терминале. Службу бота останавливать не нужно. На Ubuntu amd64 от root:

```bash
cd /opt/paintbot
bash scripts/install_browser.sh
runuser -u paintbot -- xvfb-run -a .venv/bin/python scripts/manual_browser_desktop.py \
  --browser /usr/bin/google-chrome-stable \
  --url https://www.ozon.ru/product/197922669/
```

Установщик использует официальный HTTPS-репозиторий Google и проверку подписей
APT, не меняет маршруты или настройки бота. Для системного браузера используется
отдельный `var/manual-browser-stable-profile`; прежний профиль сохраняется.
Это проверка совместимости с актуальным браузером, не средство обхода блокировок.

На Windows оставьте работающим существующий SSH-туннель к домашней VM и
снова подключитесь TigerVNC к `127.0.0.1::15901`. VNC слушает только loopback.
В браузере можно вручную пройти предложенную проверку. Если карточка доступна,
зафиксируйте видимую цену, версию браузера и время. Этот результат ещё не
подтверждает автоматический мониторинг: браузер не подключён к адаптеру бота.
Если отказ сохраняется, не повторяйте CAPTCHA и обновления по кругу. Сохраните
номер инцидента и время для поддержки Ozon; не отправляйте cookies или токены.

Для остановки нажмите Ctrl+C в терминале браузера. Бот работает отдельно.
