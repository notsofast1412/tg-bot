# Проверки Windows-версии 0.2

27 октября 2026 года, МСК: 40 Python-тестов, 36 пройдено, 4 проверки окна пропущены в Linux без графического сеанса. Семь JavaScript-тестов проверяют точность цены, отсутствие подмены обычной ценой, выдачу заданий, остановку при паузе и сохранность пользовательской вкладки. Проверены синтаксис JavaScript, ruff и компиляция Python.

Тесты локального HTTP-моста проверяют loopback-привязку, код подключения и Origin, одноразовое задание, SKU, тип цены, паузы и невозможность повторного события. Тест в Chromium выполняет настоящий JavaScript извлечения видимой цены из синтетического DOM с подписью Ozon Карты и «без WB Кошелька». Это не реальные ответы площадок.

В тестовом управляемом Chromium этой облачной среды загрузка распакованного расширения запрещена администратором (`Loading of unpacked extensions is disabled by the administrator`). Политика не менялась. Поэтому полная связка установленного расширения, браузера и приложения здесь не проверена. Её ещё нужно проверить на домашней Windows-VM, где пользователь подтвердил доступность обеих карточек в обычном Chrome.

Новая Windows-сборка и новые графические clipboard-тесты проверяются через конкретный запуск GitHub Actions. До получения его результатов они не считаются пройденными.

## История проверки версии 0.1

Проверено 27 октября 2026 года, МСК. Локальная среда: Linux, Python 3.12.14, системный Chromium. Это не пользовательская Windows-VM.

Команда: `PAINTWATCH_TEST_BROWSER=/usr/bin/chromium .venv/bin/python -m unittest discover -s tests -v`.

Результат: 31 тест, 29 пройдено, 2 проверки окна пропущены из-за отсутствия графического сеанса. `ruff check`, `ruff format --check`, проверка компиляции Python и `pip check` прошли.

Проверены:

- ссылки, артикулы, пакетное добавление, дубликаты и точные денежные единицы;
- цена Ozon только по карте, SKU, продавец, размер и остаток WB;
- строгое пересечение порога, первое событие, отсутствие повторов ниже порога, сохранение состояния при ошибках;
- редактирование порогов, индивидуальные исключения, пауза и удаление;
- SQLite backup, восстановление неопределённой отправки после аварии, блокировка второго экземпляра;
- очередь Telegram, успешная отправка, неизвестный результат, RetryAfter и запрет отправки по устаревшей/неуспешной проверке;
- планировщик и сохранение следующего срока после перезапуска;
- четыре сценария настоящего Chromium с перехваченными синтетическими ответами: чтение Ozon в той же сессии, использование ответа страницы WB, остановка при CAPTCHA, отсутствие нового запроса приложения после HTTP 429.

Браузерные тесты не обращаются к маркетплейсам и не подтверждают доступ к настоящим ценам. Контейнерный тестовый браузер работает headless с настройками Playwright для тестовой среды. Продуктовый браузер запускается с видимым окном и включённым Chromium sandbox.

В workflow `Windows application` добавлены тесты Windows/Linux, проверка окна, реального Windows DPAPI и smoke test упакованного EXE. Их выполнение и готовность артефакта нужно проверять по результату конкретного запуска Actions; локальная проверка их не заменяет. PowerShell-установщик и Windows-упаковка в этой Linux-среде не выполнялись.

На домашней Windows-VM остаются проверки: живые WB/Ozon, реальная цена по карте, сохранение ручной сессии, отправка в нужную Telegram-группу, трей, автозапуск и работа после перезагрузки/отключения RDP. На момент этой проверки они не выполнены.
