# Адаптеры и ограничения

Единый контракт: `async fetch(CardRef) -> Snapshot`. Денежная величина — целые копейки RUB либо `None`. `FetchError` содержит безопасный код и объяснение без credentials. Строгая проверка домена/пути и ID карточки не позволяет заменить результат поисковой выдачей, рекомендацией или чужим товаром.

## WildberriesAdapter

Основной метод: HTTPS GET `card.wb.ru/cards/v4/detail`, параметры `nm`, `curr=rub`, `dest`, `appType`. Выбирается ровно один продукт с совпавшим `id`/`nmId`, затем конкретный `sizes[].optionId`, если он указан в ссылке. Используется только `price.product` (копейки); зачёркнутая цена не подставляется. Несколько размеров без выбора, подтверждённые нулевые остатки или неоднозначная цена дают карточку без подтверждённой цены. Поле `volume` не трактуется как количество.

При изменении JSON/ошибке серверного метода предусмотрены HTTP-страница с JSON-LD, затем необязательный Playwright с JSON-LD. При ограничении доступа обход или серия запросов к другим адресам не выполняется. Возврат чужого ID завершает проверку ошибкой, без подбора аналога. Если прошлый успешный результат содержал продавца, а новый его не подтверждает или показывает другого, цена не принимается.

Фактически: для пользовательской карточки `29220564` API вернул пустой HTTP 403 (источник отказа не установлен), обычная страница — HTTP 498 с проверкой WBAAS AntiBot. Интеграция WB в текущей среде не подтверждена. Нужен разрешённый источник, с которого обычные запросы допустимы; сама установка библиотеки не устраняет этот отказ. У отдельного теста Chromium также выявлена ошибка доверия к CA прокси; проверка TLS не отключается. В автоматических тестах проверяется схема на тестовых данных, а не реальная доступность. Подробности: [диагностика](wb-investigation.md).

## OzonAdapter

Основной метод: HTTPS GET `www.ozon.ru/api/composer-api.bx/page/json/v2?url=/product/SKU/`.

- `webStickyProducts-*` должен подтвердить точный SKU/ссылку и название.
- Ровно один `webPrice-*` и доступный товар; `cardPrice` с явными рублями — отслеживаемая цена по карте, по уточнению владельца.
- `price` — обычная цена, хранится справочно. `originalPrice`, цена за литр, рассрочка, рекламные и рекомендательные цены не используются.
- Если `cardPrice` отсутствует, цена мониторинга остаётся неизвестной; обычная цена не становится её заменой.
- Продавец берётся из подтверждённого sticky-виджета. Его изменение/потеря подтверждения при дальнейшей проверке — ошибка, а не незаметная подмена предложения.
- Характеристики извлекаются из `webCharacteristics-*`/`webShortCharacteristics-*`. Цвет доступен в проверенной карточке. Объём и количество не выводятся из названия или тега; отсутствующие поля можно уточнить вручную с отметкой «Владелец».

Резерв: HTTP JSON-LD, затем необязательный Playwright JSON-LD. `Offer.price` не доказывает, что это цена по карте, поэтому в таком резервном результате сохраняются карточка и справочная обычная цена, а цена мониторинга остаётся неизвестной. Это ограничение резервного источника явно видно в статусе.

Фактически на `196525150` получены название Arton A108 Mr Nuts, SKU, продавец `38248`, цвет `Nuts коричнево-красный`, цена по карте 655 ₽ и обычная 718 ₽. Проверка выполнена без CAPTCHA, авторизации и browser stealth. Доступность площадки и цена могут измениться; проверенная схема сохранена без tracking-полей в `tests/fixtures/ozon-196525150.json`.

## Сеть и расписание

Для основных методов нужны HTTPS-домены `card.wb.ru`, `www.wildberries.ru`, `wildberries.ru`, `www.ozon.ru`, `ozon.ru`, для Telegram — `api.telegram.org`. Установка Python-зависимостей использует PyPI. Браузер может дополнительно запрашивать разрешённые статические поддомены WB/Ozon; их нужно добавлять в настройки egress по фактическим отказам, не заменяя неизвестный allowlist. Браузерный route блокирует посторонние ресурсы и навигацию за пределы карточек, а картинки/медиа/шрифты не загружает.

HTTPX использует стандартные proxy-переменные среды; Telegram и Playwright также учитывают `HTTPS_PROXY`. Значения не выводятся. Прокси с дополнительной аутентификацией/особой корпоративной схемой требует проверки на целевом сервере. TLS и хеши зависимостей не отключаются.

Между запросами одной площадки не менее `REQUEST_GAP` секунд, соединения сериализованы по площадке. На временную сеть/5xx — не более двух HTTP-попыток с паузой. HTTP 401/403/429/498 и CAPTCHA не ретраятся сразу, устанавливают cooldown. Следующая проверка товара сохраняется в БД и после ошибок отодвигается до суток. Увеличение интервалов — обязанность оператора при более строгих правилах площадки; автоматический обход ограничений отсутствует.

Ответ с явным `Age > 0`, просроченной `priceValidUntil`, другой валютой, чужой карточкой или отсутствием подтверждённой отслеживаемой цены не обновляет достоверную цену. Старые данные видны только вместе со временем предыдущего успеха. Время наблюдения — время получения ответа; это не гарантия мгновенного обновления внутренних данных самого маркетплейса.

Сокращённые ссылки, URL поиска, произвольные домены, `userinfo`, заданный порт и неоднозначные артикулы продавцов не поддерживаются. WB и Ozon используют числовые ID карточек; буквенно-цифровой seller article не заменяется результатом поиска — бот предлагает прямую ссылку.
