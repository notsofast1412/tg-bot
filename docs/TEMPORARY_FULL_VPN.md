# Временный тест общего исходящего IPv4 через WireGuard

Исполнять только на реальном сервере владельца, в активном SSH-подключении.
Нужен уже работающий namespace `paintbot-ru` и исходящий WireGuard.
Это диагностический тест на **5 минут**, не постоянная конфигурация.

Скрипт `scripts/full_vpn_test.py` создаёт отдельную таблицу маршрутов 42420 и
правила с приоритетами 10000–10040. Сначала регистрируется systemd-таймер отката.
Основная таблица маршрутов и firewall VPS не изменяются. Forwarding и NAT
временно включаются только внутри собственного namespace, чтобы направить через
него соединения с хоста. Исходящие IPv4-запросы, включая DNS, используют VPN.

Прямыми остаются текущий SSH-клиент (адрес берётся из `SSH_CONNECTION`), Endpoint
`95.161.4.67`, непосредственно подключённые сети и текущие IPv4-адреса
`api.telegram.org`. Эти адреса Telegram фиксируются только на время теста;
изменение DNS-ответов во время теста не отслеживается. Исключение SSH не
распространяется на новые подключения с другого внешнего IP.

Подготовленный туннель IPv4-only: внешний IPv6 на время теста получает маршрут
`unreachable`, чтобы соединения не обходили VPN. IPv6-настройки интерфейсов не
меняются; временное правило и таблица удаляются при откате.

```bash
cd /opt/paintbot
runuser -u paintbot -- git pull --ff-only origin main
apt-get install -y nftables
install -o root -g root -m 644 scripts/full_vpn_test.py /usr/local/libexec/paintbot-full-vpn-test.py
python3 -I /usr/local/libexec/paintbot-full-vpn-test.py start
```

Дождитесь `TEST ACTIVE`. В течение следующих пяти минут:

```bash
curl -4 --noproxy '*' --connect-timeout 10 --max-time 20 https://api.ipify.org
echo
systemctl list-timers paintbot-full-vpn-rollback.timer --no-pager
```

Выход ожидается `95.161.4.67`. Проверка Telegram выполняется существующим
`scripts.verify_server`. Сам бот продолжает использовать прежний VPN-прокси для
WB/Ozon. Чтобы проверить браузер **без CONNECT-прокси**, сначала остановите старый
рабочий стол (Ctrl+C в его SSH-окне), затем во время активного теста запустите:

```bash
runuser -u paintbot -- xvfb-run -a .venv/bin/python scripts/manual_browser_desktop.py --direct
```

SSH-туннель/VNC остаются прежними. После автоматического отката браузер с
`--direct` снова использует обычный выход VPS: остановите его после теста.

Досрочный откат:

```bash
python3 -I /usr/local/libexec/paintbot-full-vpn-test.py rollback
```

Не отключайте таймер, чтобы продлить тест. Для нового теста сначала дождитесь
отката и убедитесь, что старые transient units удалены systemd. Блокировки Ozon
и CAPTCHA могут сохраниться: изменение маршрута не гарантирует получение цены.

Логика исключений SSH/Telegram, порядка регистрации таймера и ограниченного
отката проверена с моками. Реальное переключение маршрутов на сервере владельца
не выполнялось агентом и требует проверки по фактическому результату команд.
