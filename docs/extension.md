# Расширение обычного браузера

Версия 0.4 использует обычный Chrome/Edge с расширением. Запускайте его вручную в Windows, где карточки открываются. При желании создайте отдельный профиль браузера через его штатное меню и установите расширение туда.

## Подключение

1. Обновите программу и завершите прежний PaintWatch через «Выход», чтобы старый процесс и управляемые окна браузера завершились.
2. В новом окне должно быть написано `PaintWatch 0.4.2`.
3. «Настройки» → «Открыть папку расширения». В сборке это папка `extension` рядом с EXE; в исходниках — `extension` в корне проекта.
4. В Chrome откройте `chrome://extensions`, включите «Режим разработчика» и загрузите эту папку кнопкой «Загрузить распакованное расширение». В Edge — `edge://extensions`.
5. В PaintWatch нажмите «Скопировать код». Откройте окно расширения, вставьте код и нажмите «Подключить». Это код локальной связи, не Telegram-токен.
6. Сохраните Telegram-настройки, отправьте тест в группу, добавьте карточки и включите мониторинг. Chrome и приложение должны оставаться запущенными.

Если установка распакованных расширений запрещена администратором браузера, она требует разрешения владельца политики. Программа не изменяет политики браузера.

## Проверка цены

Расширение поддерживает пул из 1–32 одновременных проверок (по умолчанию 4). Для задания создаётся временная неактивная вкладка. После результата или ошибки она закрывается, прежде чем слот получит следующий товар: вкладки не накапливаются. Если пользователь перевёл служебную вкладку на другой товар/сайт, расширение оставляет её открытой.

Одноразовые вкладки записываются в session storage расширения. При возобновлении service worker оставшиеся записанные вкладки удаляются, если они всё ещё принадлежат проверкам. Полная перезагрузка браузера/расширения может очистить session storage: вкладки, оставшиеся от прежней версии, тогда нужно закрыть вручную. Кнопка «Открыть проверяемую карточку» заново открывает последнюю карточку в обычной активной вкладке для ручной проверки; эта вкладка автоматически не закрывается.

Расширение начинает чтение в новом документе карточки, не ждёт загрузки всех изображений. Видимая подтверждённая цена возвращается немедленно; изменения DOM отслеживаются наблюдателем до общего лимита чтения. Для Ozon, если за первые 1,5 секунды (либо 10% короткого лимита) цена не появилась, возможен один резервный запрос API (до 5 секунд в оставшемся бюджете). WB проверяется только по видимой цене с Кошельком, запрос к API с обычной ценой не выполняется. При отказе API наблюдение страницы продолжается, и появившаяся подтверждённая цена возвращается немедленно. Для доставки результата оставляется небольшой запас до жёсткого таймаута. Общий лимит чтения — 20 секунд по умолчанию; настройка «Лимит времени» допускает 1–120 секунд. Это предельное ожидание, а не обязательная задержка. Слишком короткий лимит может не дать странице показать цену.

Свободные слоты заполняются сразу после результата; при отсутствии заданий приложение опрашивается примерно раз в секунду. Системный alarm каждые 30 секунд восстанавливает работу после остановки service worker браузером; поэтому при приостановке браузера точный секундный график не гарантируется. Нужен Chrome/Edge 120+.

Интервал товара задаётся в секундах без прежнего минимума в десять минут. `0` означает непрерывный обход всего списка. Отсчёт обычного интервала идёт от завершения проверки. Активные задания сохраняются в SQLite с одноразовыми ключами и сроком, повторные интервалы не создают дубликаты. Снижение параллельности не отменяет уже начатые задания. Ошибки получают отдельную возрастающую паузу от пяти секунд; ограничения площадки — отдельную паузу не менее минуты или больше по Retry-After.

Для Ozon читается видимая цена с явной подписью Ozon Карты. Для WB по последнему указанию пользователя читается **полная видимая цена `x ₽` из элемента `mo-typography_colors_danger`**. Вариант `mo-typography_color_danger` из первого присланного фрагмента также поддержан. На примерах это 261 ₽ и 444 ₽ по WB Карте; 270/664 ₽ без карты и зачёркнутые 379/869 ₽ не используются.

Поиск не зависит от тегов `h2`, `span`, `strong`, номера товара, `priceBlockWalletPrice`, `priceBlockFinalPrice` или меняющихся хешей. Название товара необязательно: вместо отсутствующего `h1` передаётся артикул, а настоящее название подхватится позже. Элемент должен содержать целую положительную цену в рублях: проценты, отрицательная скидка, смешанный текст и несколько сумм не принимаются. Скрытые и зачёркнутые значения исключаются. Одинаковые дубли объединяются; разные найденные цены возвращают `ambiguous_card_price`.

Новая цена возвращается немедленно после появления. До общего лимита наблюдается обновление DOM. Если WB не показал цену с Кошельком, возвращается неизвестная цена, обычная не подставляется. Сервер проверяет тип `wb_wallet`, артикул, вариант и известного продавца. Старый тип `wb_product` и WB JSON с обычной ценой отвергаются. Ozon сохраняет один резервный запрос внутри той же сессии без экспорта cookies.

Цена из DOM относится к региону текущего браузера. Цена WB с Кошельком относится к текущей сессии и региону браузера; поле `dest` не меняет её. Резервный запрос к API WB больше не используется. Сверьте регион, продавца и вариант при первой проверке. Карточки с несколькими размерами требуют подтверждения конкретного размера.

Обычный браузер и расширение тоже могут получить ограничение площадки. Пройдите CAPTCHA вручную и нажмите «Я прошёл проверку» в приложении. Кнопка не снимает HTTP 429. Если цена по карте не подтверждена, обычная цена её не заменяет.

## Приватность

Расширение имеет разрешения только для Ozon, WB и loopback. Локальный сервер приложения слушает исключительно `127.0.0.1:18765`, проверяет код подключения, Origin и одноразовое задание. Входящие порты снаружи открывать не нужно. Telegram-токен хранится в приложении под DPAPI и в расширение не передаётся. Код подключения хранится в локальном хранилище расширения; не публикуйте его.

Данные товаров по-прежнему находятся в `%LOCALAPPDATA%\PaintWatch`. Файл `extension.dpapi` — защищённый код подключения. Обычный профиль Chrome хранится в штатном месте браузера, программа не читает его файлы cookies.

## После обновления

Данные, история и Telegram-настройки сохраняются отдельно от исходников/EXE. Если папка расширения обновилась, нажмите «Обновить» на карточке PaintWatch в `chrome://extensions`, затем перезагрузите открытые карточки товаров. Код подключения остаётся прежним под той же учётной записью Windows.


Приложение 0.4.2 и расширение 0.4.3 совместимы. Для исправления отсутствующего заголовка и общего механизма распознавания достаточно обновить только расширение. Старое расширение не подтверждает новый тип цены WB; новое сообщает о необходимости обновить старое приложение. Завершите приложение через «Выход», замените файлы, запустите новый EXE, обновите расширение в `chrome://extensions` и проверьте доступ к WB и Ozon.


## Диагностика распознавания

Откройте нужную карточку в обычной вкладке Chrome и дождитесь цены. Нажмите значок расширения → «Диагностика цены открытой карточки». Выделенный отчёт можно скопировать Ctrl+C. Для отчёта не требуется запущенное приложение. Расширение с разрешением `scripting` запускает актуальный упакованный файл извлечения цены в изолированном контексте вкладки с уже выданным доступом к площадке, затем читает отчёт. Старый обработчик сообщения во вкладке не используется, перезагружать страницу для замены этого обработчика не требуется.

В отчёте — версия расширения, артикул, распознанная цена, роли и классы элементов блока цен. HTML, cookies, токены, адрес доставки и данные аккаунта не включаются. Диагностика не делает запросов к API площадки, не закрывает вкладку и не меняет мониторинг. Если браузер не разрешает запуск, проверьте доступ расширения к этой площадке; политики браузера не меняются автоматически.

«Нет связи с PaintWatch по 127.0.0.1:18765» относится к локальному приложению, а не к WB. Запустите PaintWatch.exe, проверьте версию и нажмите «Подключить». Для мониторинга соединение нужно, для диагностики страницы — нет. Если порт отвечает не как PaintWatch, проверьте приложение, занявшее его.


## Обновление только расширения

1. Остановите мониторинг и дождитесь завершения текущих проверок.
2. В последнем успешном GitHub Actions скачайте **PaintWatch-extension**.
3. Распакуйте содержимое архива с заменой в установленную папку `extension`. Например, `C:\Apps\PaintWatch\extension\manifest.json` должен существовать непосредственно по этому пути. Путь загруженного расширения можно проверить в его сведениях в Chrome.
4. В `chrome://extensions` нажмите ↻ для PaintWatch; должна появиться версия **0.4.3**.
5. Подключите расширение, откройте карточку и нажмите «Проверить все сейчас» в приложении.

EXE 0.4.2, токен, товары и история остаются прежними. Отдельный артефакт содержит только файлы расширения и доступен после успешных Linux-тестов; он подходит для Chrome/Edge на Windows.
