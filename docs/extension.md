# Расширение обычного браузера

Версия 0.4 использует обычный Chrome/Edge с расширением. Запускайте его вручную в Windows, где карточки открываются. При желании создайте отдельный профиль браузера через его штатное меню и установите расширение туда.

## Подключение

1. Обновите программу и завершите прежний PaintWatch через «Выход», чтобы старый процесс и управляемые окна браузера завершились.
2. В новом окне должно быть написано `PaintWatch 0.4.10`.
3. «Настройки» → «Открыть папку расширения». В сборке это папка `extension` рядом с EXE; в исходниках — `extension` в корне проекта.
4. В Chrome откройте `chrome://extensions`, включите «Режим разработчика» и загрузите эту папку кнопкой «Загрузить распакованное расширение». В Edge — `edge://extensions`.
5. В PaintWatch нажмите «Скопировать код». Откройте окно расширения, вставьте код и нажмите «Подключить». Это код локальной связи, не Telegram-токен.
6. Сохраните Telegram-настройки, отправьте тест в группу, добавьте карточки и включите мониторинг. Chrome и приложение должны оставаться запущенными.

Если установка распакованных расширений запрещена администратором браузера, она требует разрешения владельца политики. Программа не изменяет политики браузера.

## Проверка цены

Расширение поддерживает пул из 1–32 одновременных проверок (по умолчанию 4). Для задания создаётся временная неактивная вкладка. После результата или ошибки она закрывается, прежде чем слот получит следующий товар. Обычное завершение проверки оставляет вкладку, которую пользователь перевёл на другой товар/сайт. Отдельная периодическая очистка, описанная ниже, закрывает и такие вкладки.

С версии 0.4.7 флажок **«Не загружать фото и видео при проверках»** включён по умолчанию. Сессионные правила Chrome блокируют ресурсы `image` и `media` только для ID проверочной вкладки и инициаторов Ozon/WB. Сначала создаётся вкладка, затем устанавливается правило, поэтому самые ранние запросы могут успеть начаться. Скрипты, стили, шрифты и запросы цен не блокируются. Обычные пользовательские вкладки и вкладка ручной проверки не получают правил. Если сайт перестал показывать цену, выключите флажок; он действует на новые проверки.

При завершении, ошибке и таймауте правила удаляются вместе со служебной вкладкой. При возобновлении service worker удаляются оставшиеся правила, не принадлежащие активным проверкам. Если пользователь перевёл вкладку на другой товар, правило удаляется, а вкладка остаётся. Браузерное разрешение `declarativeNetRequest` нужно для этих правил; при обновлении Chrome может запросить его подтверждение.

Одноразовые вкладки записываются в session storage расширения. При возобновлении service worker оставшиеся записанные вкладки удаляются, если они всё ещё принадлежат проверкам. Полная перезагрузка браузера/расширения может очистить session storage; вкладки без этой записи также удалит периодическая очистка. Кнопка «Открыть проверяемую карточку» заново открывает последнюю карточку в обычной активной вкладке для ручной проверки; обычное завершение проверки её не закрывает, периодическая очистка закрывает.

Переход Ozon на `/search/?product_id=исходный_артикул` остаётся частью той же проверки. После чтения или ошибки эта служебная вкладка также закрывается. Если переход сменил документ во время чтения, расширение ждёт новый документ того же товара в оставшемся бюджете, сохраняя единственный слот и задание. Поиск без `product_id`, с другим или неоднозначным артикулом не считается исходной карточкой; вкладка, переведённая пользователем на такой адрес, сохраняется.

Расширение начинает чтение в новом документе карточки, не ждёт загрузки всех изображений. Видимая подтверждённая цена возвращается немедленно; изменения DOM отслеживаются наблюдателем до общего лимита чтения. Для Ozon, если за первые 1,5 секунды (либо 10% короткого лимита) цена не появилась, возможен один резервный запрос API (до 5 секунд в оставшемся бюджете). WB проверяется только по видимой цене с Кошельком, запрос к API с обычной ценой не выполняется. При отказе API наблюдение страницы продолжается, и появившаяся подтверждённая цена возвращается немедленно. Для доставки результата оставляется небольшой запас до жёсткого таймаута. Общий лимит чтения — 20 секунд по умолчанию; настройка «Лимит времени» допускает 1–120 секунд. Это предельное ожидание, а не обязательная задержка. Слишком короткий лимит может не дать странице показать цену.

Свободные слоты заполняются сразу после результата; при отсутствии заданий приложение опрашивается примерно раз в секунду. Системный alarm каждые 30 секунд восстанавливает работу после остановки service worker браузером; поэтому при приостановке браузера точный секундный график не гарантируется. Нужен Chrome/Edge 120+.

Интервал товара задаётся в секундах без прежнего минимума в десять минут. `0` означает непрерывный обход всего списка. Отсчёт обычного интервала идёт от завершения проверки. Активные задания сохраняются в SQLite с одноразовыми ключами и сроком, повторные интервалы не создают дубликаты. Снижение параллельности не отменяет уже начатые задания. Ошибки получают отдельную возрастающую паузу от пяти секунд; ограничения площадки — отдельную паузу не менее минуты или больше по Retry-After.

Для Ozon читается видимая цена с явной подписью Ozon Карты. С расширения **0.4.9** WB сначала ищет полную видимую цену в блоке Кошелька: классы с префиксом `priceBlockWalletPrice` без привязки к хешу или `price-block__wallet-price`. Если таких блоков нет, ищет компактную строку с явной подписью «с WB Кошельком» / «при оплате WB Кошельком». Поддерживаются вложенные подписи, отдельные узлы суммы и валюты, цена и подпись одним текстом. Обычная цена API не подставляется, скидка Кошелька не вычисляется по проценту.

Если ни блока, ни явной подписи Кошелька нет, сохраняется совместимое чтение `mo-typography_colors_danger`, `mo-typography_color_danger`, `mo-typography_colors_accent`. Подтверждённый блок с отсутствующей или неоднозначной ценой не заменяется этой резервной веткой. Значения внутри распознанных карточек рекомендаций, ссылок на карточки и контейнеров с чужим артикулом исключаются; продавцы таких карточек также не мешают определению основного продавца. Цена без Кошелька, скидки в рублях, баллы, рассрочка, скрытые и зачёркнутые значения не принимаются. Одинаковые суммы объединяются, разные подтверждённые суммы дают `ambiguous_card_price`.

Поиск не зависит от тега суммы и хеша CSS-класса. Название необязательно: вместо отсутствующего `h1` передаётся артикул, настоящее название подхватится позже. Для прежнего HTML с суммой 278 ₽ в `mo-typography_colors_accent` поддержка сохраняется. Диагностика показывает `walletEvidence.source`: `wallet_container`, `wallet_label` или `legacy_color`, число найденных блоков и подтверждённые суммы. Это помогает отличить смену разметки от отсутствующей цены без передачи HTML или данных аккаунта.

Новая цена возвращается немедленно после появления. До общего лимита наблюдается обновление DOM. Если WB не показал цену с Кошельком, возвращается неизвестная цена, обычная не подставляется. Сервер проверяет тип `wb_wallet`, артикул, вариант и известного продавца. Старый тип `wb_product` и WB JSON с обычной ценой отвергаются. Ozon сохраняет один резервный запрос внутри той же сессии без экспорта cookies.

Цена из DOM относится к региону текущего браузера. Цена WB с Кошельком относится к текущей сессии и региону браузера; поле `dest` не меняет её. Резервный запрос к API WB больше не используется. Сверьте регион, продавца и вариант при первой проверке. Карточки с несколькими размерами требуют подтверждения конкретного размера.

Обычный браузер и расширение тоже могут получить ограничение площадки. Пройдите CAPTCHA вручную и нажмите «Я прошёл проверку» в приложении. Кнопка не снимает HTTP 429. Если цена по карте не подтверждена, обычная цена её не заменяет.

## Очистка всех вкладок раз в 30 минут

В расширении **0.4.8** по запросу пользователя включён флажок **«Раз в 30 минут закрывать все вкладки, кроме одной»**. Он действует после подключения расширения. Очистка охватывает все доступные расширению окна и вкладки этого профиля браузера, включая личные и закреплённые; для PaintWatch рекомендуется отдельный профиль. Другие профили и другие браузеры не затрагиваются. Дополнительного доступа к содержимому посторонних страниц не требуется: закрытие выполняется по ID вкладки.

При наступлении срока новые задания перестают выдаваться этому расширению. Текущие проверки и отправка их результатов завершаются в обычном порядке, зависшие проверки ограничены прежним таймаутом. Расширение продолжает опрашивать статус приложения, пока активные задания не закончатся. После перезапуска учитываются и задания, сохранённые в приложении.

Затем расширение создаёт или сохраняет одну лёгкую вкладку PaintWatch и закрывает остальные вкладки, включая старые страницы без записи о владельце. Перед закрытием проверяется наличие оставляемой вкладки. Удаляются оставшиеся правила блокировки медиа и записи служебных вкладок. Следующий срок отсчитывается через 30 минут после успешной очистки. Новые проверки возобновляются по текущему состоянию мониторинга; остановленная пользователем программа сама не запускается.

При сбое закрытия вкладок или потере связи с приложением очистка повторяется, а новые проверки остаются на паузе. Флажок можно выключить. Срок хранится в локальном хранилище расширения, поэтому перезапуск service worker или браузера его не сбрасывает. Во время сна браузера очистка откладывается до пробуждения. Первая автоматическая очистка после установки или включения флажка — через 30 минут. Кнопка **«Очистить вкладки сейчас»** запускает тот же порядок без ожидания, даже если автоочистка выключена. Статус виден в окне расширения.

## Приватность

Расширение имеет разрешения только для Ozon, WB и loopback. Локальный сервер приложения слушает исключительно `127.0.0.1:18765`, проверяет код подключения, Origin и одноразовое задание. Входящие порты снаружи открывать не нужно. Telegram-токен хранится в приложении под DPAPI и в расширение не передаётся. Код подключения хранится в локальном хранилище расширения; не публикуйте его.

Данные товаров по-прежнему находятся в `%LOCALAPPDATA%\PaintWatch`. Файл `extension.dpapi` — защищённый код подключения. Обычный профиль Chrome хранится в штатном месте браузера, программа не читает его файлы cookies.

## После обновления

Данные, история и Telegram-настройки сохраняются отдельно от исходников/EXE. Если папка расширения обновилась, нажмите «Обновить» на карточке PaintWatch в `chrome://extensions`, затем перезагрузите открытые карточки товаров. Код подключения остаётся прежним под той же учётной записью Windows.


Текущая связка — приложение **0.4.10**, расширение **0.4.9**. Для нового чтения WB достаточно обновить расширение: EXE 0.4.7 менять не требуется. Расширение совместимо с приложением не ниже 0.4.5, но статистика скорости и сокращение пустых запросов требуют приложения 0.4.7. После замены папки расширения нажмите ↻ в `chrome://extensions` и проверьте версию 0.4.9. Новых разрешений по сравнению с расширением 0.4.7 не добавлено.

## Товар закончился

На подтверждённом переходе Ozon в поиск с единственным числовым `product_id`, совпадающим с заданием, видимая отдельная надпись «Товар закончился» / «Нет в наличии» завершает проверку без чтения цен рекомендаций и без резервного запроса API. В обычной карточке поддерживается такой же явный основной заголовок `h1`. Одна фраза в отзыве, скрытый текст, подпись карточки другого товара или сам факт перехода в поиск отсутствия товара не подтверждают. Ответ API Ozon с подтверждённым SKU и единственным `webPrice.isAvailable=false` также считается отсутствием товара. CAPTCHA и HTTP 429 остаются ограничениями доступа.

В приложении показывается «Товар закончился» и «—» вместо текущей цены. Последняя история цен, продавец и условия сохраняются; ошибок и уведомлений из-за отсутствия товара нет. Ожидающие ценовые события отменяются, товар остаётся включённым и проверяется по заданному интервалу. После возврата та же уже отправленная цена повторно не уведомляется; новое снижение от неё на 15 ₽ уведомляется как раньше. Сообщение, уже отправляемое в Telegram до подтверждения отсутствия, отозвать нельзя.


## Диагностика распознавания

Откройте нужную карточку в обычной вкладке Chrome и дождитесь цены. Нажмите значок расширения → «Диагностика цены открытой карточки». Выделенный отчёт можно скопировать Ctrl+C. Для отчёта не требуется запущенное приложение. Расширение с разрешением `scripting` запускает актуальный упакованный файл извлечения цены в изолированном контексте вкладки с уже выданным доступом к площадке, затем читает отчёт. Старый обработчик сообщения во вкладке не используется, перезагружать страницу для замены этого обработчика не требуется.

В отчёте — версия расширения, артикул, распознанная цена, роли и классы элементов блока цен. HTML, cookies, токены, адрес доставки и данные аккаунта не включаются. Диагностика не делает запросов к API площадки, не закрывает вкладку и не меняет мониторинг. Если браузер не разрешает запуск, проверьте доступ расширения к этой площадке; политики браузера не меняются автоматически.

«Нет связи с PaintWatch по 127.0.0.1:18765» относится к локальному приложению, а не к WB. Запустите PaintWatch.exe, проверьте версию и нажмите «Подключить». Для мониторинга соединение нужно, для диагностики страницы — нет. Если порт отвечает не как PaintWatch, проверьте приложение, занявшее его.


## Обновление приложения и расширения

1. Остановите мониторинг и дождитесь завершения текущих проверок.
2. Завершите PaintWatch через «Выход». В последнем успешном GitHub Actions скачайте **PaintWatch-Windows-x64** и замените всю папку программы вместе с `_internal` и `extension`.
3. Проверьте путь загруженного расширения в его сведениях Chrome: обновлена должна быть именно эта папка. Например, `C:\Apps\PaintWatch\extension\manifest.json` должен существовать непосредственно по этому пути.
4. Запустите PaintWatch 0.4.10. В `chrome://extensions` нажмите ↻ для PaintWatch; должна появиться версия **0.4.9**. При переходе с расширения старше 0.4.7 Chrome может запросить разрешение блокировки запросов.
5. Подключите расширение, откройте карточку и нажмите «Проверить все сейчас» в приложении.

Токен, товары и история сохраняются в `%LOCALAPPDATA%\PaintWatch`. Отдельный артефакт **PaintWatch-extension** доступен после Windows-тестов. Если приложение уже 0.4.7, для очистки замените только содержимое загруженной папки расширения этим артефактом и нажмите ↻ в Chrome. После обновления можно сразу проверить кнопку «Очистить вкладки сейчас».

Команды упоминаний `/tagall` требуют приложения 0.4.10; обновление одного расширения их не добавляет.
