# Личное управление PaintWatch

Сохраните токен бота в Windows-приложении. В личном чате с этим ботом отправьте `/id`; он вернёт ваш Telegram ID. Введите его в «Настройки → Ваш ID для ЛС», нажмите «Сохранить», затем отправьте `/start` и `/help`. Ценовые уведомления по-прежнему идут в группу с отдельным отрицательным ID. С версии 0.4.2 WB отслеживается с WB Кошельком, Ozon — по карте.

Номер владельца задаётся только в приложении. Посторонние пользователи и команды в группах игнорируются. `/id` доступна любому пользователю в личном чате и сообщает только его собственный ID, без доступа к данным PaintWatch. Пересылка текста команды не меняет её отправителя.

| Команда | Действие |
|---|---|
| `/status` | Мониторинг, количество товаров, активные и ожидающие проверки, интервал |
| `/run`, `/stop` | Включить или остановить мониторинг; ЛС остаются доступны при остановке |
| `/products 2` | Страница списка по 15 товаров; первый столбец — внутренний ID |
| `/add #arton https://www.ozon.ru/product/196525150/` | Добавить товар с порогом выбранного тега; можно несколько ссылок |
| `/delete 12` | Показать товар и команду подтверждения |
| `/delete 12 confirm` | Удалить товар №12 вместе с историей и ожидающими уведомлениями |
| `/pause 12`, `/resume 12` | Выключить или включить товар №12 |
| `/scan` | Разово проверить все включённые товары сейчас, не включая расписание; ограничения площадок сохраняются |
| `/tags` | Список тегов и порогов |
| `/tag #montana 400` | Создать свой тег с порогом 400 рублей |
| `/check 12`, `/check all` | Пересчитать срок проверки по выбранному интервалу; паузы площадок сохраняются |
| `/verified 12` | Повторить после ручного прохождения проверки в Chrome; не отменяет HTTP 429 |
| `/interval 60` | Интервал между завершением проверки товара и следующей попыткой, в секундах |
| `/interval 0` | Непрерывный обход списка |
| `/parallel 8` | До 8 проверок одновременно; диапазон 1–32 |
| `/threshold 12 400.50` | Индивидуальный порог товара №12 в рублях |
| `/errors` | Первые 10 текущих проблем и их общее количество |
| `/help` | Список команд |

Число `12` — ID строки в программе, не артикул маркетплейса. Одинаковая карточка повторно не добавляется. Смена порога сама по себе не отправляет ценовое событие. В уже открытой вкладке настроек программы остаётся введённый пользователем текст; при переходе из других вкладок значения интервала и параллельности синхронизируются с базой.

Разовый `/scan` работает и при остановленном расписании. В этом случае он обновляет цены, а отправка ценовых событий в группу остаётся на паузе. `/stop` отменяет незавершённый разовый обход.

## Кнопки и ценовые уведомления

Приложение 0.4.1 при запуске обновляет меню команд и присылает новую нижнюю клавиатуру в личный чат настроенного владельца. Кнопки: «Статус», «Проверить все», «Запустить», «Остановить», «Товары», «Теги», «Добавить товар», «Добавить тег», «Удалить товар», «Помощь». Добавление/удаление открывают подсказки по нужным командам; удаление требует подтверждения. `/start` или `/help` повторно показывают клавиатуру. Кнопки не дают доступа другим пользователям и не добавляются к ценовым сообщениям в группе.

Первое уведомление приходит при подтверждённой цене строго ниже порога. Пока цена остаётся ниже порога, повтор — при снижении ещё минимум на **15 ₽ от последней успешно отправленной цены**. Снижения по 1 ₽ накапливаются: после сообщения о 350 ₽ следующее придёт при 335 ₽ или ниже, затем после сообщения о 335 ₽ — при 320 ₽ или ниже. Колебания 335 → 350 → 335 ₽ ниже порога не повторяют сообщение о 335 ₽.

До отправки хранится одно актуальное ожидающее событие товара. Если сообщение ещё не отправлено и цена падает дальше, придёт актуальная цена; отдельные сообщения на каждый промежуточный шаг не копятся. Если повтор ожидал отправки, но цена восстановилась и снижение стало меньше 15 ₽, повтор отменяется. Явно отклонённая отправка не меняет исходную отметку. Неопределённый результат требует проверки группы и ручного решения о повторе; до этого дополнительные повторы в текущем периоде ниже порога не создаются.

Если цена поднялась до порога или выше и затем снова стала ниже, начинается новое первое событие. Изменение порога само по себе не рассылает уведомления: для дальнейших снижений исходной отметкой становится текущая известная цена. При первом обновлении со старой версии также используется текущая известная цена, чтобы не угадывать цену исторического сообщения и не присылать старые события повторно. Отметка переживает перезапуск.

## Сообщения о проблемах

Программа отправляет владельцу сводки об ошибках чтения цены и доступа, необходимости ручной проверки, отсутствии связи с расширением более 90 секунд при включённом мониторинге и ошибках доставки в группу. В одной сводке до шести примеров, полный список доступен в приложении. Новая сводка — не чаще раза в минуту; неизменная повторяется не чаще раза в 30 минут, в том числе после перезапуска программы. Ошибки отдельных товаров сохраняются до успешной проверки.

Если Telegram явно отклонил отправку, программа ждёт указанную паузу перед повтором. При потерянном ответе сводка не повторяется немедленно: повторная отправка может создать дубликат. Это ограничение Telegram API.

ЛС и управление работают, пока приложение запущено и есть доступ к Telegram. Для сбора цен также нужны обычный браузер и подключённое расширение. При выключенном компьютере, закрытом приложении, недействующем токене или потере сети сообщение через того же бота доставить невозможно. Ошибка Telegram отображается в настройках приложения; после восстановления связи работа возобновится.

## Если бот не отвечает

- Сначала сохраните токен в приложении, затем отправьте `/id` из личного чата. При первой активации старые накопленные команды пропускаются; подождите несколько секунд и отправьте команду заново.
- Укажите положительный ID вашего пользователя, а не ID группы или username. В личном чате нажмите «Начать»; заблокированный вами бот не может прислать сообщение.
- Код 409 при получении команд означает конфликт: проверьте другой запущенный экземпляр бота или настроенный webhook. PaintWatch не удаляет webhook автоматически.
- Команда запоминается до исполнения и не выполняется повторно при перезапуске. Если приложение аварийно завершилось в этот момент или ответ потерялся, проверьте `/status` и `/products` перед повторной командой.
