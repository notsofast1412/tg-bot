# Telegram: управление и упоминания

Сохраните токен бота в Windows-приложении. В личном чате с этим ботом отправьте `/id`; он вернёт ваш Telegram ID. Введите его в «Настройки → Ваш ID для ЛС», нажмите «Сохранить», затем отправьте `/start` и `/help`. Ценовые уведомления по-прежнему идут в группу с отдельным отрицательным ID. С версии 0.4.2 WB отслеживается с WB Кошельком, Ozon — по карте.

Номер владельца задаётся только в приложении. Управление ценами доступно только этому владельцу в ЛС; такие команды в группах игнорируются. В настроенной группе отдельно работают команды упоминаний: владельцу и администраторам доступны `/tagall`, `/tagall_status`, `/tagall_cancel`, всем участникам — `/here`. Другие группы не обрабатываются. `/id` доступна любому пользователю в личном чате и сообщает только его собственный ID, без доступа к данным PaintWatch.

| Команда | Действие |
|---|---|
| `/status` | Мониторинг, товары, очередь, интервал, темп проверок и возраст результатов |
| `/run`, `/stop` | Включить или остановить мониторинг; ЛС остаются доступны при остановке |
| `/products 2` | Страница списка по 15 товаров; первый столбец — внутренний ID |
| `/add #arton https://www.ozon.ru/product/196525150/` | Добавить товар с порогом выбранного тега; можно несколько ссылок |
| `/add #belazo 1797187018` | Выбрать площадку кнопкой и добавить артикул с указанным тегом |
| `1797187018` | Бот спросит площадку, затем тег; можно несколько артикулов через пробел или новую строку |
| `/cancel` | Отменить незавершённое добавление |
| `/delete 12` | Показать товар и команду подтверждения |
| `/delete 12 confirm` | Удалить товар №12 вместе с историей и ожидающими уведомлениями |
| `/pause 12`, `/resume 12` | Выключить или включить товар №12 |
| `/scan` | Разово проверить все включённые товары сейчас, не включая расписание; ограничения площадок сохраняются |
| `/tags` | Список тегов и порогов |
| `/tag #montana 400` | Создать свой тег с порогом 400 рублей |
| `/check 12`, `/check all` | Пересчитать срок проверки по выбранному интервалу; паузы площадок сохраняются |
| `/verified 12` | Повторить после ручного прохождения проверки в Chrome; не отменяет HTTP 429 |
| `/interval 60` | Интервал между завершением проверки товара и следующей попыткой, в секундах |
| `/interval 0` | Непрерывный обход списка |
| `/parallel 8` | До 8 проверок одновременно; диапазон 1–32 |
| `/threshold 12 400.50` | Индивидуальный порог товара №12 в рублях |
| `/errors` | Первые 10 текущих проблем и их общее количество |
| `/help` | Список команд |
| `/tagall` | Упомянуть известных участников по username или Telegram ID |
| `/tagall_status` | Размер известного списка, ход отправки и ошибки |
| `/tagall_cancel` | Остановить оставшиеся порции упоминаний |
| `/here` | В группе добавить свой аккаунт в список упоминаний |

## Упомянуть участников группы

Нужно приложение **0.4.11** для поддержки упоминаний без username. Обновление только расширения эту функцию не добавляет. В приложении сохраните отрицательный ID нужной группы и сделайте бота её администратором: это нужно для событий состава группы и надёжной проверки членства. Отправьте `/tagall` в группе; это разрешено владельцу PaintWatch и администраторам. Владелец также может отправить `/tagall` в личный чат бота — упоминания всё равно пойдут в настроенную группу. Другие команды управления ценами остаются только в ЛС владельца.

**Bot API не отдаёт полный список участников.** Программа запоминает отправителей полученных сообщений, события входа/выхода и администраторов. Уже существующим молчаливым участникам, которых бот ещё не видел, нужно один раз отправить `/here` в группе. После этого достаточно одной `/tagall`. Людей без username команда упоминает по отображаемому имени через Telegram ID; боты пропускаются. Неизвестные программе участники автоматически не обнаруживаются; полный охват старой группы без их участия не обещается.

Для добавления себя по ID достаточно отправить **`/here` в самой группе**. Telegram ID берётся из отправителя автоматически; вручную вводить число или открывать username не требуется. Если username отсутствует, сообщение содержит кликабельное имя с упоминанием через ID. Имя берётся из свежего ответа Telegram при отправке; если оно пустое, используется «Участник». Одинаковые имена разных людей обрабатываются отдельно.

Перед каждой порцией проверяется текущее членство через Telegram и обновляется username. Вышедшие участники пропускаются. Упоминания отправляются по пять имён в сообщении. Для всех отправок этого бота в одну группу, включая ценовые сообщения, действует общий интервал не менее 3,2 секунды. Подготовка следующей порции идёт между обработкой команд; группа не получает длинное обрезанное сообщение.

`/tagall_status` показывает известный список, число подтверждённо отправленных имён и состояние задания. `/tagall_cancel` отменяет оставшиеся порции; уже отправленные сообщения остаются. Повторная `/tagall` во время активной отправки не создаёт второе задание. Команду можно адресовать боту как `/tagall@имя_бота`; команды другому боту, пересланные команды и сообщения от постороннего канала не запускают упоминания. Анонимный администратор, пишущий от имени самой группы, поддерживается.

Список и прогресс сохраняются отдельно для токена бота и группы. Тексты обычных сообщений и имена профилей не сохраняются — только ID, username и состояние участия. При изменении группы оставшееся задание отменяется. Потеря прав администратора у автора команды или бота также останавливает отправку. При явном отказе Telegram применяется его пауза; если ответ отправки потерялся или приложение завершилось во время неё, автоматического повтора нет. Проверьте чат и `/tagall_status` перед новой `/tagall`: новая команда после такого сбоя начинает список заново.

Приложение должно оставаться запущенным. Меню группы обновляется автоматически; `/here` остаётся доступной всем участникам, а общие упоминания требуют прав. На настоящей группе работу нужно проверить после обновления приложения.

## Управление товарами

Число `12` — ID строки в программе, не артикул маркетплейса. Одинаковая карточка повторно не добавляется. Смена порога сама по себе не отправляет ценовое событие. В уже открытой вкладке настроек программы остаётся введённый пользователем текст; при переходе из других вкладок значения интервала и параллельности синхронизируются с базой.

С версии 0.4.7 `/status` показывает статистику расширения за последние пять минут (после старта — за прошедшее время): завершённые и успешные проверки, успешные проверки в минуту, среднюю длительность попытки, число включённых товаров без успешного результата и возраст самого старого успешного результата. Подтверждённое отсутствие товара считается успехом; ошибки входят в число попыток и среднюю длительность. Повторные проверки одного товара также входят в темп, поэтому оценивайте его вместе с охватом списка. Статистика ограничена последними 4096 попытками и сбрасывается при перезапуске; охват берётся из сохранённых результатов товаров.

Расчёт обхода равен числу включённых товаров, умноженному на среднюю длительность попытки и делённому на число слотов. Он не учитывает интервал, паузы площадок, очередь браузера и передачу результата, поэтому не обещает срок следующей проверки. Для непрерывного обхода всех 621 товаров начните с `/parallel 6` и `/interval 0`, подождите пять минут и сравните `/status` с загрузкой ВМ.

Разовый `/scan` работает и при остановленном расписании. В этом случае он обновляет цены, а отправка ценовых событий в группу остаётся на паузе. `/stop` отменяет незавершённый разовый обход.

## Добавление по артикулу

С приложения 0.4.6 просто отправьте артикул в личный чат, например `1797187018`. Бот спросит «На какой площадке искать артикул?» и покажет кнопки **Ozon** и **Wildberries**. После выбора появятся кнопки существующих тегов. Выберите тег или напишите его сообщением; товар добавится с порогом этого тега, а обычная панель управления вернётся. При большом количестве тегов доступны страницы «Далее» / «Назад».

Если тег уже указан в `/add #belazo 1797187018`, бот спросит только площадку и сохранит выбранный тег. Поддерживаются несколько числовых артикулов; выбранная площадка относится ко всем числам в этом сообщении. Полные ссылки в смешанном пакете сохраняют собственную площадку. `/add #тег полная_ссылка` добавляет товар сразу. Короткие ссылки вида `ozon.ru/t/…` по-прежнему требуют раскрытия в обычном браузере.

Пока площадка и тег не выбраны, товары не добавляются и мониторинг не включается. «Отмена», `/cancel` и `/start` сбрасывают выбор; новое сообщение с артикулом заменяет предыдущий незавершённый запрос. `/status`, `/stop` и другие команды управления остаются доступны во время выбора. Состояние привязано к владельцу и боту, переживает перезапуск приложения и истекает через 15 минут. Чужие ответы и сообщения в группах его не изменяют. Дубликаты пропускаются, а добавление и очистка запроса записываются одной транзакцией.

## Кнопки и ценовые уведомления

Приложение при запуске обновляет меню команд и присылает новую нижнюю клавиатуру в личный чат настроенного владельца. Кнопки: «Статус», «Проверить все», «Запустить», «Остановить», «Товары», «Теги», «Добавить товар», «Добавить тег», «Удалить товар», «Помощь». Добавление/удаление открывают подсказки по нужным командам; удаление требует подтверждения. `/start` или `/help` повторно показывают клавиатуру. Кнопки не дают доступа другим пользователям и не добавляются к ценовым сообщениям в группе.

Первое уведомление приходит при подтверждённой цене строго ниже порога. Пока цена остаётся ниже порога, повтор — при снижении ещё минимум на **15 ₽ от последней успешно отправленной цены**. Снижения по 1 ₽ накапливаются: после сообщения о 350 ₽ следующее придёт при 335 ₽ или ниже, затем после сообщения о 335 ₽ — при 320 ₽ или ниже. Колебания 335 → 350 → 335 ₽ ниже порога не повторяют сообщение о 335 ₽.

До отправки хранится одно актуальное ожидающее событие товара. Если сообщение ещё не отправлено и цена падает дальше, придёт актуальная цена; отдельные сообщения на каждый промежуточный шаг не копятся. Если повтор ожидал отправки, но цена восстановилась и снижение стало меньше 15 ₽, повтор отменяется. Явно отклонённая отправка не меняет исходную отметку. Неопределённый результат требует проверки группы и ручного решения о повторе; до этого дополнительные повторы в текущем периоде ниже порога не создаются.

Если цена поднялась до порога или выше и затем снова стала ниже, начинается новое первое событие. Изменение порога само по себе не рассылает уведомления: для дальнейших снижений исходной отметкой становится текущая известная цена. При первом обновлении со старой версии также используется текущая известная цена, чтобы не угадывать цену исторического сообщения и не присылать старые события повторно. Отметка переживает перезапуск.

## Сообщения о проблемах

Подтверждённое отсутствие товара с версии 0.4.5 показывается как «Товар закончился» в приложении и списке товаров. Оно не входит в `/errors` и не вызывает уведомлений в группе или личном чате. Ожидающие сообщения о цене отменяются до возврата товара; проверки по расписанию продолжаются.

Программа отправляет владельцу сводки об ошибках чтения цены и доступа, необходимости ручной проверки, отсутствии связи с расширением более 90 секунд при включённом мониторинге и ошибках доставки в группу. В одной сводке до шести примеров, полный список доступен в приложении. Новая сводка — не чаще раза в минуту; неизменная повторяется не чаще раза в 30 минут, в том числе после перезапуска программы. Ошибки отдельных товаров сохраняются до успешной проверки.

Если Telegram явно отклонил отправку, программа ждёт указанную паузу перед повтором. При потерянном ответе сводка не повторяется немедленно: повторная отправка может создать дубликат. Это ограничение Telegram API.

ЛС и управление работают, пока приложение запущено и есть доступ к Telegram. Для сбора цен также нужны обычный браузер и подключённое расширение. При выключенном компьютере, закрытом приложении, недействующем токене или потере сети сообщение через того же бота доставить невозможно. Ошибка Telegram отображается в настройках приложения; после восстановления связи работа возобновится.

## Если бот не отвечает

- Сначала сохраните токен в приложении, затем отправьте `/id` из личного чата. При первой активации старые накопленные команды пропускаются; подождите несколько секунд и отправьте команду заново.
- Укажите положительный ID вашего пользователя, а не ID группы или username. В личном чате нажмите «Начать»; заблокированный вами бот не может прислать сообщение.
- Код 409 при получении команд означает конфликт: проверьте другой запущенный экземпляр бота или настроенный webhook. PaintWatch не удаляет webhook автоматически.
- Команда запоминается до исполнения и не выполняется повторно при перезапуске. Если приложение аварийно завершилось в этот момент или ответ потерялся, проверьте `/status` и `/products` перед повторной командой.
