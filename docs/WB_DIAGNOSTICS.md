# WB: браузер открывает карточку, бот получает 403

Старый `card.wb.ru/cards/v2/detail` возвращал 403. Браузер подтвердил новый
источник `/__internal/u-card/cards/v4/detail`: товар 518397236, вариант 716573024,
цена 26300 копеек, остаток 52. Бот теперь использует этот браузерный источник;
прямой API-запрос удалён.

Перед изменением источника проверяем ответы, которые получает сама открытая
карточка. `scripts/wb_browser_probe.py` запускает обычную страницу через Playwright
с тем же браузером и профилем, что ручной VNC-запуск. Он не обращается к API
напрямую: собирает только ответы штатной страницы, поля выбранного товара и
видимые блоки цен. Возможное отличие результата от ручного запуска фиксируется,
а не считается успешным получением цены. Заголовки, cookies и полные ответы
с токенами не экспортируются. Прокси, подмена браузерных свойств и отключение TLS
не используются.

На Ubuntu остановите только ранее запущенный VNC-браузер через Ctrl+C, затем:

```bash
cd /opt/paintbot
runuser -u paintbot -- env PLAYWRIGHT_BROWSERS_PATH=/opt/paintbot/var/chromium \
  xvfb-run -a .browser-probe/bin/python scripts/wb_browser_probe.py \
  'https://www.wildberries.ru/catalog/518397236/detail.aspx?size=716573024'
```

Playwright должен быть установлен в отдельном `.browser-probe`, как при проверке
Ozon. Диагностика и бот используют общий профиль и файловый lock. Во время активной
проверки другого процесса может появиться ошибка занятости. Диагностика использует системный Chrome,
если он установлен, иначе ранее установленный Chromium. Профиль не удаляется.

Нужны `page_http`, `same_card_and_size`, `responses`, `products` и `price_blocks`.
Данные сверяются с видимой карточкой, её size и условиями цены. Отдельный диагностический запуск не добавляет товары и не отправляет сообщения.
В обычном режиме `scripts.manage probe` и бот запускают тот же worker автоматически.

Парсер API поддерживает `optionId` и старый `chrtId`. Несогласованные ID
не подтверждают выбранный вариант. Если у варианта нет `stocks`, общее
`totalQuantity` подтверждает наличие только у карточки с единственным вариантом.
Наличие нескольких вариантов и общего остатка недостаточно для назначения
цены одному из них. Неизвестная цена остаётся неизвестной.

## Проверка обновлённого адаптера

```bash
cd /opt/paintbot
runuser -u paintbot -- .venv/bin/python -m scripts.manage probe \
  'https://www.wildberries.ru/catalog/518397236/detail.aspx?size=716573024'
```

Ожидаются точный `card_id` с size и актуальная `price_kopecks` (26300 была ценой
на момент первоначальной диагностики; последующие цены могут измениться).
Далее добавьте ссылку в Telegram и проверьте новую запись мониторинга.
Для перехода с существующей версии `.env` и миграции схемы менять не требуется.
