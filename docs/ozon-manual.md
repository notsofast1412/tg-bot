# Ручная проверка Ozon в браузере сервера

Этот инструмент открывает настоящий Chromium на сервере, а изображение и управление передаёт через noVNC и SSH-туннель. CAPTCHA решает владелец вручную. TLS и Chromium sandbox включены. Stealth, подмена browser fingerprint и автоматическое решение CAPTCHA не применяются.

## Подготовка на сервере

В существующем каталоге проекта:

```bash
cd /opt/paintwatch
sudo git pull --ff-only origin main
sudo apt-get update
sudo apt-get install -y xvfb xauth x11vnc novnc websockify
sudo .venv/bin/python -m playwright install-deps chromium
sudo -u paintwatch env PLAYWRIGHT_BROWSERS_PATH=/opt/paintwatch/data/browsers .venv/bin/python -m playwright install chromium
```

Запуск (этот терминал остаётся открытым):

```bash
sudo -u paintwatch env PLAYWRIGHT_BROWSERS_PATH=/opt/paintwatch/data/browsers .venv/bin/python scripts/ozon_manual.py
```

Отдельный профиль сохраняется в `data/ozon-browser` с правами 700; не публикуйте и не пересылайте его. База бота и `.env` инструментом не меняются. Журнал процессов рабочего стола: `data/ozon-browser/desktop.log`.

## Подключение с компьютера

Откройте второй терминал **на своём компьютере**, замените `USER` и `SERVER`:

```bash
ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:6080:127.0.0.1:6080 USER@SERVER
```

Для нестандартного SSH-порта добавьте `-p PORT`. Оставьте терминал открытым. В браузере компьютера откройте:

```text
http://127.0.0.1:6080/vnc.html?autoconnect=true&resize=scale
```

Это рабочий стол браузера именно на сервере, с его сетевым адресом. Пройдите CAPTCHA самостоятельно. Если видите сообщение об ограничении доступа без возможности проверки, сохраните текст сообщения: успешный доступ не гарантирован. После проверки закройте окно Chromium крестиком, чтобы профиль корректно сохранился, и завершите SSH-туннель через Ctrl+C.

VNC и noVNC слушают только loopback сервера. VNC не имеет отдельного пароля и предназначен для доверенной машины, где локальные пользователи имеют соответствующие полномочия; удалённый доступ защищён SSH. Не открывайте порты 5901/6080 в firewall, не меняйте адрес прослушивания на `0.0.0.0` и не публикуйте рабочий стол в Интернете.

## Что это проверяет

Успешное ручное прохождение подтверждает доступ только для этой браузерной сессии. HTTP-клиент действующего бота пока её не использует. После успешной проверки нужно отдельно подключить сборщик к сохранённому браузерному профилю и проверить реальное получение `cardPrice`. Передача одних cookies не гарантирует, что HTTP-клиент будет допущен. Профиль не следует одновременно открывать в двух процессах Chromium.

Инструмент не проверялся на пользовательском сервере. Локальная проверка Python или тесты бота не подтверждают прохождение CAPTCHA или доступность Ozon через этот браузер.
